# Contributing to Awesome Vendor Security Questionnaires

Contributions from founders, security engineers, and compliance auditors are welcome!

### How to Contribute
1. Fork this repository.
2. Add auditor-vetted sample answers, new questionnaire frameworks (e.g., VSAC, HECVAT, CyberGRX), or update existing controls for 2026 standards.
3. Submit a Pull Request with a clear description of the control domain and rationale.

For bespoke institutional compliance vaults or done-for-you review turnaround, visit [The Runbook Index](https://runbookindex.com).
